การจัดการหน่วยความจำ

บนคอมพิวเตอร์

หน่วยความจำเสมือน (Virtual Memory): ใช้เนื้อที่ฮาร์ดดิสก์เป็นที่พักข้อมูล Swap File: เก็บข้อมูลในฮาร์ดดิสก์สำหรับโปรแกรมที่ทำงาน Page: แบ่งข้อมูลออกเป็นส่วนๆ ที่มีขนาดแน่นอน โหลดเฉพาะเพจที่ใช้ → เมื่อ RAM เต็มก็ถ่ายเทเพจที่ไม่ใช้ไปเก็บในดิสก์

บนสมาร์ตโฟน

ไม่ใช้ Virtual Memory เหมือนคอมพิวเตอร์ Flash Memory เร็วต่ำกว่า SSD มีข้อจำกัดอายุการใช้งาน มาตรการเป็นลำดับขั้น: หยุดแอปที่ไม่ใช้งาน → บีบอัดข้อมูล → บังคับปิดแอป (ข้อมูลอาจสูญหาย) แอปต้องบันทึกข้อมูลล่วงหน้า (ในเครื่องหรือบนคลาวด์)
