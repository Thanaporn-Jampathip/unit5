บทที่ 5 ระบบปฏิบัติการและหลักการทํางาน
หน้าหลัก ระบบปฏิบัติการ การบู๊ตและ CPU หน่วยความจำ การจัดการไฟล์ ความปลอดภัย ผู้จัดทำ

รายการหัวข้อ

ขั้นตอนการเริ่มต้นระบบ (Boot)

  1. เริ่มจ่ายไฟ: กดปุ่มเปิด → พาวเวอร์ซัพพลายจ่ายไฟให้ซีพียู
  2. ซีพียูเริ่มทำงาน: อ่านโปรแกรม BIOS/Firmware จาก Flash ROM
  3. ตรวจสอบอุปกรณ์ (POST): ตรวจสอบความพร้อมเมนบอร์ด RAM ซีพียู อุปกรณ์ต่อพ่วง
  4. โหลดระบบปฏิบัติการ: อ่านจาก Flash ROM หรืออุปกรณ์อื่น (ฮาร์ดดิสก์, SSD) เก็บใน RAM
  5. Kernel พร้อมใช้งาน: เริ่มทำงาน โหลด Configuration แสดงหน้าจอพร้อมรับคำสั่ง

ประเภทของการบู๊ตเครื่อง

  • วอร์มบู๊ต (Warm Boot): ให้เริ่มทำงานใหม่ (รีสตาร์ท/Soft Reset)
    บางครั้งอาจเคลียร์ค่าไม่หมด สมาร์ตโฟนเมื่อปิดผ่านเมนูเป็น Soft Reset

  • โคลด์บู๊ต (Cold Boot): เริ่มต้นฮาร์ดแวร์ใหม่จริงๆ (Hard Reset)
    โปรแกรมและข้อมูลใน RAM หายไป ต้องโหลด OS ใหม่หมด ใช้เวลานานกว่า แต่แน่ใจได้ว่าปัญหาจะหายไป

การจัดการหน่วยประมวลผล (CPU Management)

  • Time Sharing: แบ่งเวลาเป็นช่วงให้โปรแกรมต่างๆ ทีละอัน
  • Multi-core CPU: มีหลาย core ทำงานหลายโปรแกรมพร้อมกันได้จริงๆ
  • Performance core + Efficiency core: OS จัดสรรงานให้เหมาะสม หรือปิด core ที่ไม่ใช้
  • GPU (Graphics Processing Unit): ช่วยงานกราฟิกและการคำนวณแบบคู่ขนาน
  • NPU (Neural Processing Unit): ช่วยงาน AI เร็วกว่า GPU และประหยัดพลังงาน

การจัดการอุปกรณ์นำเข้าและแสดงผล (I/O Device Management)

  • บัฟเฟอร์ (Buffer): พื้นที่พักข้อมูลชั่วคราว (ในหน่วยความจำหรือฮาร์ดดิสก์)
  • Spooling สำหรับการพิมพ์: Print Queue เก็บงานพิมพ์และทยอยส่งไปเครื่องพิมพ์
  • Device Driver: จำเป็นต้องติดตั้งเพื่อให้ OS สั่งงานอุปกรณ์ได้อย่างถูกต้อง
  • Plug and Play: ติดตั้งอุปกรณ์ใหม่ OS ค้นหาและติดตั้งไดรเวอร์โดยอัตโนมัติ
